# Vladimir Pak — Personal Portfolio

Static Codecademy portfolio built with HTML, CSS and JavaScript. Open index.html locally. No build tools required.

## Features
- Home and contact pages
- Three existing GitHub projects; Blog Website featured first
- Project category filtering with accessible status updates
- Persistent light/dark theme and copy email button
- Responsive layouts and keyboard focus styles
- Original SVG project illustrations (conceptual previews, not screenshots)

## Plan and wireframe
Header/navigation → introduction and monogram illustration → filterable three-column project gallery → about and skills → contact CTA → footer. On narrow screens, sections stack vertically. Contact page offers mailto and GitHub links.

## Deployment
Publish these files in a GitHub Pages source directory. All asset links are relative and support subdirectory hosting.
